# KayesDev 🚀

> Full-Stack Portfolio + Learning Management Dashboard

A modern, production-ready portfolio and admin dashboard built with the latest web technologies. Features a public portfolio with ISR, role-based admin dashboard, and MCP server integration.

## Features

**Public Portfolio**
- Hero, About, Skills, Projects, Education, Contact sections
- Dark/Light theme toggle (dark default)
- Lenis smooth scroll
- Framer Motion animations
- ISR (Incremental Static Regeneration)
- SEO optimized with dynamic metadata

**Dashboard**
- Project CRUD with tech stack tagging
- Skill management with proficiency bars
- Learning log tracker with markdown support
- Notes system with pinning and color coding
- Role-based access (admin vs user)

**Auth**
- NextAuth v5 with JWT strategy
- Credentials provider
- Middleware route protection
